# Отчёт: АСКА-02 + УЗСГ-01

**Дата работ:** 14 ноября 2026  
**Станционный узел:** Ubuntu `rekon` (`station-edge`)  
**Адаптер:** АСКА-02, ООО «Техно Проект», выпуск 07.2026, FTDI FT232R S/N `A5069RR4`  
**Колонка:** УЗСГ-01 (пульт в помещении, модуль индикации на улице)

## Итог

Компьютер и АСКА-02 связаны: запросы протокола «Искра 1.72» на **9600 8N1** доходят до адаптера, на порту с кабелем мигают **обе** зелёные лампы. **Кадр ответа до USB не приходит** (всегда 0 байт). Узкое место — ответ пульта/модуля индикации УЗСГ-01 или неизвестная прошивка АСКА 2026 года. Инфраструктура учёта (служба, VPS REKON, Tailscale) готова принять данные, как только появятся байты.

Программа на линии **только читает** (команда «Тест», код `4`). Пуск, доза и стоп не отправлялись.

## 4. Анализ прошивок (сайт «Техно Проект»)

Скачаны и разобраны HEX: `aska_pc`, `aska_sht`, `aska_topaz`, `ASKAS`, `ASKA_elv`, `ASKA_ams`, варианты kkm. Готовой программы связи ПК↔АСКА на сайте нет.

| Находка | Следствие |
|---------|-----------|
| UART во всех HEX: `TH1=FAh`, `SMOD=0` | 4800 или 9600; по лампам рабочая 9600 |
| Большинство ждут кадр Искра 23 байта | Формат `station-edge` совпадает |
| Ответ ПК только после ответа колонки | 0 байт при молчании колонки — штатно для старых прошивок |
| Адрес 07 самоответ только в `aska_pc` | 0 на 07 не доказывает поломку USB |
| `aska_pc` — 4 канала (2011) | У нас 6 гнёзд и выпуск **07.2026** — другая прошивка |
| Драйвер «3. Driver» = Megawin MA112 | Не для этой АСКА (у нас FTDI, уже работает) |

## 5. Настройка УЗСГ-01

На этой колонке **ЗАПИСЬ** открывает **ПРОГР.** с буквами **Р Н П** (не меню шильдиков ЦЕНА/ЛИТРЫ/СУММА из старой памятки).

По инструкции для работы с СУ/АСКА:

1. Обнулить показания (СБРОС).
2. ЗАПИСЬ → ПРОГР., буквы Р Н П.
3. ПУСК = Р, СТОП = Н, СБРОС = П. Оставить **только Н и П**.
4. Снова ЗАПИСЬ.

У оператора **Н и П уже были** до наших правок.

Клеммы линии: **«К АСКА 01»**, либо **3А/2Б**, либо винты **4 и 5 слева**. Не БУН / DAT / GND.
