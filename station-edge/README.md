# Станционный узел АГЗС: УЗГС-01 (УЗСГ-01) + АСКА-02 (`station-edge`)

Автономный пакет для компьютера на заправке (Windows 10/11 или Linux), который:
1. Опрашивает газораздаточную колонку **УЗГС-01 (УЗСГ-01, «Технопроект»)** через адаптер **АСКА-02** (FTDI FT232R, `9600 8N1`) строго в режиме чтения — командой **«Тест» протокола «Искра 1.72» (код 4, адреса 1–6)**.
2. Разбирает 23-байтный ответный кадр (начинается с `0x01`, контроль BCC, адрес, 6 цифр цены, объём в миллилитрах, состояние и ошибка протокола).
3. Вычисляет фактический уход газа **`dispensed_ml`** по закрытой заправке как для **обычной дозы** (обратный отсчёт остатка: `задали − осталось`), так и для режима **«до полного»** (прямое накопление миллилитров).
4. Записывает каждую закрытую заправку в локальную базу данных станции (**SQLite WAL** `station_edge.db`).
5. Асинхронно отправляет пакеты учёта на центральный VPS (`POST /api/v1/ingest/dispense` с заголовком `X-Device-Token`) через отказоустойчивую очередь `outbox_queue` (повтор при обрыве связи не создаёт дубль заправки).

> [!IMPORTANT]
> **Аппаратная безопасность (Read-Only):**
> Компьютер на живом порту газ **не включает** и дозу не задаёт. Живой отпуск включает пистолет и кнопка на пульте УЗГС-01, аппаратный стоп — кнопка на колонке. В коде физически отсутствуют команды пуска, дозы и останова.

## 1. Памятка по подключению УЗГС-01 к АСКА-02 на станции

### Физическое подключение линии связи
- **Не врезаться** в силовые кабели насоса и колонки и **не занимать** синюю колодку «искробезопасная цепь».
- На клеммной планке пульта УЗГС-01 пара уже подписана: **два провода у наклейки «К АСКА 01»**.
- **Не брать** клеммы «К БУН-01» (блок управления насосом) и **не брать** клеммы `DAT` и `GND` (они расположены ниже, это другие винты).
- Две жилы от «К АСКА 01» обжать/посадить на **два средних контакта разъёма RJ-11** адаптера АСКА-02 (контакты 2 и 3 из 4). Крайние контакты RJ-11 не использовать. *(У старой АСКА-01 на этом месте был разъём «колокольчик», у АСКА-02 — RJ-11, физический смысл пары тот же).*
- **Полярность:** инструкция не задаёт, какая жила на левом среднем контакте. Если при опросе вторая зелёная лампа на АСКА-02 молчит — **поменять эти две жилы местами один раз**.

### Индикация на корпусе АСКА-02 (три лампы)
1. **Красная «Сеть»** — собственное питание адаптера 220 В (USB от компьютера эту часть не питает).
2. **Первая зелёная «Обмен» (сторона ПК)** — мигает, когда компьютер шлёт команду «Тест» в `COM7`.
3. **Вторая зелёная (сторона пульта УЗГС-01)** — мигает при ответе пульта. Если молчит — нет связи по паре «К АСКА 01» или перепутана полярность двух средних контактов RJ-11.

### Что считать успехом при проверке на стенде
- Пульт УЗГС-01 включён, вторая зелёная лампа на АСКА-02 мигает в такт опросу.
- В ответ на команду «Тест» (код 4) приходит кадр «Искра 1.72»: **23 байта**, начинается с `01`, верная контрольная сумма.
- В кадре читаются: адрес (`1..6`), цена (6 цифр), объём в миллилитрах (`volume_ml`), состояние и ошибка протокола (включая аварию `06`).
- Суммарник с табло (клавиши `9 0 2`), счётчик за смену (`9 0 1`) и прошлая заправка (`9 0 5`) в кадр не входят — суммарник `9 0 2` сверяется отдельно при закрытии смены.

## 2. Быстрый старт на компьютере станции (Windows 10/11 и Linux)

### Установка

```powershell
cd station-edge
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Отредактируйте `.env` (укажите `AGZS_SERIAL_PORT=COM7`, `AGZS_DEVICE_TOKEN`, `AGZS_STATION_ID`, `AGZS_TANK_ID`).

### Команды пусконаладки и работы

1. **Разовая проверка порта и опрос адресов 1–6 (проверка живой пары и второй зелёной лампы):**
   ```powershell
   python -m agzs_edge probe --port COM7 --all-addresses
   ```
2. **Живой монитор кадров в реальном времени (без записи в БД и без отправки на VPS):**
   ```powershell
   python -m agzs_edge listen --port COM7 --addr 1
   ```
3. **Боевой запуск на станции (опрос `COM7` + запись `dispensed_ml` в SQLite + отправка на VPS):**
   ```powershell
   python -m agzs_edge serve
   ```
   *(На Windows можно запускать через `run_station_edge.bat` с автоперезапуском; на Linux — через `station-edge.service`).*
4. **Проверка всего контура на Windows без подключённой колонки (режим имитатора):**
   ```powershell
   python -m agzs_edge serve --emulator --cycles 8 --no-sync
   python -m agzs_edge status
   ```
5. **Просмотр локальной базы и очереди на VPS:**
   ```powershell
   python -m agzs_edge status
   ```
6. **Принудительная доотправка очереди на VPS:**
   ```powershell
   python -m agzs_edge flush
   ```

## 3. Калибровка смещений кадра на станции

Стандартная раскладка 23-байтного кадра вынесена в класс [`FrameLayout`](agzs_edge/config.py) в файле `agzs_edge/config.py`. Если при снятии первого живого кадра с вашей ревизии пульта УЗГС-01 окажется, что 6 цифр цены и 6 цифр объёма стоят в другом порядке или используется другая контрольная сумма (`xor` / `sum7` / `sum8`), достаточно переключить `AGZS_ISKRA_CHECKSUM_MODE` в `.env` или скорректировать срезы в `FrameLayout`.
